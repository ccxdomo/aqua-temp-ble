## Lessons learned
- AC-5-style grep bans are LITERAL: symbol names may not survive even
  in comments, log strings or self-tests — grep the components for
  every deleted name AFTER the code edit, before the tests.
- sed is the right tool for mechanical multi-site replacements
  (options=_open_options() → {} across 3 files, ~30 sites, zero risk);
  the edit tool stays for structural rewrites.
- The edit tool is atomic per batch: one mismatched oldText rolls back
  the WHOLE batch (hit twice; the fix: split the failing edit into
  smaller blocks anchored on freshly re-read text).
- Line-wrap is the #1 oldText killer in prose/docstrings: re-read the
  exact section (with its line breaks) before editing long text; for
  substring assertions over Markdown, normalize whitespace first
  (" ".join(text.split())).
- When a PRUNE removes a kwarg, grep the TESTS for the callers' helper
  clients too: the scripted fakes needed new methods (write_setpoint)
  before the inverted tests could run.
