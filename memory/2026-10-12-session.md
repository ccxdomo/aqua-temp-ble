## Decisions
- PUSHED_MODE_VALUE_TO_NAME is a SEPARATE dict, NOT an extension of the base
  MODE_VALUE_TO_NAME: adding 4→"heat" to the base map would corrupt the
  classic write path's reverse map (HVAC_TO_MODE_VALUE[HEAT] would become 4
  instead of 1). The name→HVACMode layer (MODE_NAME_TO_HVAC) is the reused
  part, as FR-7 intends.
- hvac_action: OFF when power False; None (unknown) when power True — the
  compressor state is uncalibrated, and the mode register following power
  does not prove heating activity (spec 001: no optimistic state).
- The climate entity is NOT created in push mode with the gate closed —
  aligning the code with contract 013 §4.4, which the shipped 0.10.0 climate
  violated by creating it unconditionally (all-unknown state). Spec 015
  FR-8/T-B3 pins the absence; flagged in the report as a deliberate gap fix.
- push_control_raws ride the snapshot gate-INDEPENDENTLY (FR-10 diagnostics
  — the diff must be runnable before/without confirmation; entity states
  remain strictly gated).
- Read-only surface: hvac_modes=[] renders no mode buttons in the UI while
  the reported hvac_mode stays free-form; supported_features=0 hides every
  write affordance; the four write entry points raise explicitly anyway.

## Lessons learned
- The parent's diff fragments ("...07d1 0000 0001 0000... 0d 00a8 0000...")
  aligned against the pinned frames.txt grammar would place the flips at
  2011/2019, while the directive pins 2025/2034 ("offset +2/+21 in the
  block" — the offsets do not reconcile under any single base I could
  derive). The directive was followed (the orchestrator owns the evidence);
  the verification step (quickstart §5, compare hvac_mode against the app
  after opening the gate) is the decisive check, and a mis-pin is a one-line
  PUSHED_CONTROL edit. Recorded as the top caveat in the report.
- A decoded block frame carries ALL 45 registers including zeros — synthetic
  test vectors must include the zero keys or an absent register decodes
  None (unknown), not False. My baseline vector initially omitted 2025: 0.
- JSON label insertions by script: keep the old label's closing quote intact
  before appending ",\n key: value" — stripping it created an unterminated
  string with a raw newline (Invalid control character). The script asserted
  before writing, so no file was corrupted.
- The once-per-session unknown-mode warning uses a separate set for the
  pushed plane (_logged_unknown_push_modes): a value warned via the base
  path must not silence the pushed path's warning for a different register.
